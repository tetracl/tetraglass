# History: milestones M0 to M6

Milestones M0 to M6 (releases 0.1.0, 0.2.0 and 0.3.0) were built under an
earlier workflow that tracked tasks and progress in files. These files are
kept unchanged as a record. They are frozen: never add to them.

| File | What it is |
| --- | --- |
| `roadmap-m0-m6.md` | The roadmap with every task of M0 to M6 |
| `progress-m0-m6.md` | The per-task progress log and milestone retrospectives |
| `milestones/` | Gate records and demonstration images for M0 to M6 |

From M7 on, the roadmap is `../roadmap.md`, plans are in `../plans/`, tasks
and their state are GitHub issues, decisions are ADRs in `../adr/`, and gate
reviews are in `../reviews/`.
