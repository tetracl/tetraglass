# Roadmap

Milestones in the order they are built. Each entry has the fields Depends on,
Design, Acceptance, Out of scope and Runs, in that order; the structure rules
are in `.agents/skills/draft-design/references/design-and-roadmap.md`. Every
acceptance bullet is one sentence that one automated test can decide.

State lives on GitHub: each planned milestone has a milestone issue and one
task issue per task. This file holds no status, dates or checkboxes.

Milestones M0 to M6 were built under an earlier workflow; their roadmap is
frozen in `history/roadmap-m0-m6.md`. Milestone IDs are never reused, so the
next milestone is M7.
